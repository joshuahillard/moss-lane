# Phase 0 Priorities

The first Moss Lane corpus should keep most of its attention on the failure classes that already proved dangerous:

1. Epoch and query correctness
2. Config truth across code, DB, and dynamic layers
3. Paper/live mode separation
4. Truthful distinction between deployed and merely repo-built capability
5. Live-readiness decisions that depend on regime-specific evidence

This ordering reflects the actual project journey rather than a generic trading-bot checklist.
